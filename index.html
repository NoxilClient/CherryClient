Engineered in Rust

Every subsystem has been redesigned from first principles for deterministic performance and modern hardware.

Zero Garbage Collection

Rust's ownership model frees memory deterministically at compile time—eliminating the sudden lag spikes caused by Java GC sweeps.

WGPU & Vulkan Pipeline

Multi-threaded command buffer recording feeds your GPU directly via Vulkan, Metal, or DX12 with bindless textures and frustum culling.

Memory Safe & Secure

Immune to buffer overflows and legacy Java serialization exploits. Built-in sandboxing protects your system on public multiplayer servers.

WASM Modding API

Load high-speed plugins compiled to WebAssembly. Create custom HUD modules, keystrokes, and replay tools with near-native speed.

Async Chunk Meshing

Worker threads mesh and compress world chunks across all available CPU cores simultaneously without blocking the main render loop.

26.2 & 26.3 Protocol

Full packet-level compatibility with standard servers, realms, custom resource packs, and official Microsoft account authentication.

Under the Hood

Why rewriting the engine from scratch beats stacking optimization mods on top of Java.

Data-Oriented ECS World

Instead of scattering thousands of heap-allocated Java objects across memory, Vanta stores entities and block states in contiguous, cache-friendly arrays using an Entity Component System.

Your CPU processes thousands of entities in tight SIMD loops with minimal cache misses.

vanta_core/src/world/chunk_mesher.rs
pub fn build_chunk_mesh(chunk: &ChunkData, pool: &ThreadPool) -> GpuMesh {
  // Zero heap allocations during greedy meshing pass
  let faces = chunk.cull_occluded_faces();
  pool.submit_async(move || {
    GpuMesh::from_packed_vertices(faces)
  })
}
