Frequently Asked Questions

Everything you need to know about security, browser authentication, open source code, and performance.

Why is FastClient marked as NOT safe compared to Glacier Client?
FastClient is closed source, does not isolate sign-in through your external system browser with auditable OAuth handling, and offers no public source verification. Glacier Client is 100% open source and opens your external browser directly to official Microsoft OAuth endpoints.
Why did a single scanner flag the URL as suspicious or phishing?
Automated heuristic scanners occasionally trigger false positives on newly published *.github.io pages or game-related landing pages that reference downloads or Discord links—even when 90+ security vendors report the URL as clean.
How does Glacier Client handle authentication safely?
When you sign in, Glacier opens your external browser to authenticate directly through official Microsoft OAuth endpoints. Glacier never asks for or stores your password inside the client, and session tokens stay local on your machine.
Is Glacier Client open source?
Yes! Unlike closed-source benchmark clients, Glacier Client is open source so anyone can inspect the code, verify there is no malware or data collection, and contribute improvements.
Will I get banned on multiplayer servers?
Glacier Client is strictly a legitimate performance and HUD client—it contains zero cheats, macros, or unfair movement/combat modifications. We continuously test physics parity across 1.8.9, 26.2, and 26.3 against strict anti-cheats (such as GrimAC and Vulcan) to ensure vanilla-accurate packets.
Which Minecraft versions are supported?
Glacier Client currently supports 1.8.9 (for competitive PvP), 26.2, and 26.3. You can switch between versions effortlessly inside the Glacier Launcher.
Why is Rust faster than standard Java clients?
Standard Minecraft runs on the Java Virtual Machine (JVM), which periodically pauses the game for Garbage Collection (causing sudden FPS drops and micro-stutters). Glacier compiles directly to native machine code using Rust and wgpu, eliminating GC pauses and utilizing all CPU cores efficiently.
When will macOS be supported?
Windows and Linux builds are available right now. Native macOS support (Apple Silicon & Intel via Metal) is actively in development and will be released in an upcoming update.
