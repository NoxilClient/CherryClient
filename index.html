FAQ

What is the difference between Sodium, Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, Tori, and Glacier?
Sodium (Fabric) is an open-source rendering mod that optimizes Minecraft's chunk rendering pipeline on top of the Java Virtual Machine, whereas Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, and Tori are proprietary (non-open-source) clients that still run on the JVM and rely on bundled optimization mods and patches (such as Sodium-style rendering tweaks, OptiFine-like adjustments, and JVM flags) to improve FPS—meaning they remain bound to Java's memory model, runtime overhead, and Garbage Collector pauses. Glacier Client takes a 10x better approach: instead of patching Java with external mods, Glacier rewrites Minecraft's core engine from the ground up in native Rust with a modern wgpu renderer, deterministic memory ownership, lock-free multi-core chunk meshing, and zero Garbage Collector freezes—while staying open source with external browser OAuth and zero password storage.
How does Glacier Client handle login and passwords?
Glacier uses external browser Microsoft OAuth authentication and never asks for or stores your password inside the client.
Does Glacier Client include cheats or unfair modifications?
No. Glacier is built around performance, rendering efficiency, and clean HUD/utility parity for legitimate play.
