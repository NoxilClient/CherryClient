Frequently Asked Questions

Architecture, security, and why native Rust outperforms mod-based Java clients.

What is the difference between Sodium, Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, Tori, and Glacier?
Sodium (Fabric) is an open-source rendering mod that optimizes Minecraft's chunk rendering pipeline on top of the Java Virtual Machine, while Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, and Tori are proprietary (non-open-source) clients that still run on the JVM and rely on bundled optimization mods and patches (such as Sodium-style rendering tweaks, OptiFine-like adjustments, and JVM flags) to boost performance—meaning they remain bound to Java's memory overhead, runtime overhead, and Garbage Collector micro-stutters. Glacier Client takes a completely different, 10x better architectural approach: instead of patching Java with external mods, Glacier rewrites Minecraft's core engine from scratch in native Rust with a modern wgpu (Vulkan / DirectX 12) renderer, deterministic memory ownership, lock-free multi-core chunk meshing, and zero Garbage Collector pauses—while remaining open source with external browser OAuth and zero password storage.
How does Glacier Client handle authentication safely?
Glacier opens your external browser directly to official Microsoft OAuth endpoints. It never asks for or stores your password inside the client, and session tokens stay strictly local on your machine.
Is Glacier Client safe on anti-cheat servers?
Yes. Glacier contains zero cheats, macros, or unfair combat/movement modifications, and maintains strict tick and packet parity across 1.8.9, 26.2, and 26.3.
