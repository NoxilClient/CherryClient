Frequently Asked Questions

Detailed comparison of optimization mods, JVM-based clients, and Glacier's native Rust engine.

What is the difference between Sodium, Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, Tori, and Glacier?
Sodium (Fabric) is an open-source rendering mod that optimizes Minecraft's chunk rendering pipeline on top of the Java Virtual Machine, whereas Dawn, Lunar, Feather, Badlion, NoRisk, Silent, FastClient, and Tori are proprietary (non-open-source) clients that still run on the JVM and rely on bundled optimization mods and patches (such as Sodium-style rendering tweaks, OptiFine-like adjustments, and JVM flags) to improve FPS—meaning they remain bound to Java's runtime overhead, memory model, and Garbage Collector pauses. Glacier Client takes a 10x better architectural approach: instead of patching Java with external mods, Glacier rewrites Minecraft's core engine from scratch in native Rust with a modern wgpu renderer, deterministic memory ownership, lock-free multi-core chunk meshing, and zero Garbage Collector freezes—while staying open source with external browser OAuth and zero password storage.
How does Glacier Client handle Microsoft login safely?
Glacier uses external browser Microsoft OAuth authentication. Your credentials are entered directly in your browser—Glacier never asks for or stores your password.
Does Glacier Client include cheats or unfair PvP advantages?
No. Glacier focuses on rendering performance, native Rust stability, and legitimate HUD/utility features across 1.8.9, 26.2, and 26.3.
